# Golem Crafting Never Lucky

RuneLite Plugin Hub project for Golem Crafting.

## Current status

This repository contains the Plugin Hub project structure and a safe starter implementation.

The exact Golem Crafting trigger still needs to be wired to the current OSRS/RuneLite event or state used by the minigame. No made-up varbit or widget IDs are used.

## Development

Use Java 11 and the current RuneLite example-plugin structure.
